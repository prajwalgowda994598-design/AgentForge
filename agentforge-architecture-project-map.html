▶ START
↓
🔍 Researcher
↓
📝 Summarizer
↓
⚖️ Critic (scores 0–1)
✓ score ≥ 0.7
↓
✅ Fact Checker
↓
🧩 Synthesizer
↓
■ END
✗ score < 0.7
↓
↩ Retry Researcher
max 3 iterations

The Five Agents

🔍
Researcher
Searches FAISS + DuckDuckGo web; refines with LLM
IN: query, top_k
OUT: retrieved_chunks, refined_research
📝
Summarizer
Condenses research into structured Markdown notes
IN: refined_research
OUT: summary
⚖️
Critic
Scores quality 0–1. Routes retry or proceed.
IN: query, summary
OUT: critic_score, should_retry
✅
Fact Checker
Verifies claims against sources; annotates citations
IN: summary, chunks, snippets
OUT: verified_summary
🧩
Synthesizer
Combines all validated info into polished Markdown answer with sources
IN: verified_summary, critic_score, sources
OUT: final_answer (Markdown)

AuthJWT (python-jose), Bearer token, bcrypt passwords
Loggingstructlog (JSON in prod, console in dev)
Resiliencetenacity retry + exp. backoff, per-agent timeout
FrontendReact 18, TypeScript, Tailwind CSS, Vite, react-markdown
ContainersDocker multi-stage builds, Docker Compose v3.9
Reverse ProxyNginx (SPA routing + /api + /ws proxy)
CI/CDGitHub Actions (lint → test → Docker push → EC2 deploy)
DeploymentAWS EC2 (Ubuntu 22.04), Docker Hub registry
